## 文案取舍

删去重复的自我说明、发表保证与笼统免责。保留改变研究设计的条件，并尽量写成要检查的内容：例如基态与有限温度、轨道能与电化学窗口、tracer 与相关电导率的区别。

测试划分按任务设计：随机留出可衡量独立同分布表现；相关轨迹、同源材料与时间序列需要对应的分组隔离；预测未见物相或组成还需域外测试。

## 隐私检查

`publication_safety.py` 检查本次公开内容和暂存快照；新增的 `history_safety.py` 只检查可达 Git 对象的路径记录，区分既有问题与新增路径，不读取历史文件内容。

已确认旧 Git 历史仍有被删除的本地文献清单。本版没有重写历史，也不把“没有新增路径”称为历史已经安全。未经单独授权不强推。
