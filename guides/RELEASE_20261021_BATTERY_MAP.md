# 2026-10-21 · 从电池结构查找论文

首页搜索区下新增交互式电池剖面，用结构部位进入已有文献，而不是再建一份独立论文库。

## 使用

1. 初始只显示大幅圆柱电池剖面和六个圆点，没有论文列表或侧栏。鼠标移到部位点，或用键盘 Tab 聚焦，查看对应部位的突出/放大效果。
2. 点击圆点后，在示意图下方展开人工整理的相关论文，点击“收起论文列表”恢复初始状态。下方图例仅作说明，不自动展开论文。手机可直接点击，图在窄屏可横向滑动。
3. 点击论文标题，打开原有论文详情卡。原题、中文参考译名、DOI、方法、路线与本机可用的全文入口仍由主库维护。

六个部位为正极、负极、电解质、隔膜、界面（SEI/CEI）与集流体。本版有 37 篇既有论文、39 个交叉引用；跨部位出现的论文不是新增论文或重复题录。

## 图与分类的边界

- 采用常见石墨负极、液态电解液锂离子电池作为结构例子，不按真实厚度比例绘制。库内还有硅、二维负极、聚合物/无机固态电解质和钠体系，不能认定它们都采用图示结构。
- 电解液浸润孔隙；隔膜是电子隔离的多孔部件。部分固态电池不另设独立隔膜，不把电解质和隔膜混为一类。
- SEI/CEI 高亮指接触和反应区域，不表示所有界面都是均匀等厚的独立膜。
- 当前规范书目尚无已核实的专门隔膜、集流体论文。这两个部位保留知识说明和诚实的空列表，不用一般电极论文凑数。
- “主题直接相关”表示论文主题与该部位相关；“相关背景”表示交叉问题或方法参考，都不等于论文证明了该部位的每一句说明。具体参数与结论仍应回到原文。

结构参考使用 DOE 和 Argonne 的公开资料，链接在示意图下方。映射来自人工核对的既有题录与库内简述，不声称完成了新一轮逐篇全文参数审阅。

## 维护与发布

- `data/battery_components.json`：唯一公共部位—论文映射，使用规范 paper_id 和 DOI。
- `validate_battery_components.py`：构建前拒绝未知部位、私有字段、重复/过期引用和非允许的结构来源链接。
- `static/battery_explorer.js` / `.css`：无外部依赖的 SVG 和交互；复用现有详情弹窗，不单独存储论文全文、附件或凭据。
- `build_pages.py` 同步资源到 GitHub Pages 的 `docs/` 与本机使用的 `static/data/`。
- 可选示意图加载失败不会阻塞主检索；不根据模糊词临时补造部位论文。

```powershell
python validate_battery_components.py
python -m unittest tests.test_battery_components
node --test tests/test_battery_explorer*.mjs
python build_pages.py
python publication_safety.py --public-bundle
```

本版没有新增论文、重新训练模型、下载或写入 Zotero；结构选读与 QLoRA、全文覆盖分别维护。公共页面不展示私人附件映射。
