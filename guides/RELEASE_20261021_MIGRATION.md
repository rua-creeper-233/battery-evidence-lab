# 2026-10-21：页面细节与发布流程

公开版本从经过检查的当前快照开始。所有论文、分类、工具和学习内容继续维护；个人文库与本地上下文单独保存。

源码仓库与网页公开，通过独立的 GitHub Pages 部署经过检查的内容。旧站点停用，新的仓库从净化快照开始，不复制旧历史。

本版缩减了学习路线的搜索索引，移除目的套话和范围说明对搜索的干扰。输入采用短暂防抖，长列表使用浏览器的按需绘制。211 篇论文及其引用仍完整保留。

辅助文字在样式源文件中统一调整；构建遇到页面自建主题会报错，不再悄悄改字号。手机导航提示可滚动方向，说明按钮与复选框的点击区域扩大。装饰性英文分类改为中文，科学名称和缩写保留。

补充分享预览图、站点地图和搜索引擎入口。首页只显示论文数量与更新日期，详细统计见项目记录。

每次推送与拉取请求会运行自动测试、构建一致性检查和公开内容检查。历史检查使用完整候选历史，不以“没有新增问题”代替“历史无禁止文件”。部署仅在检查通过后执行。

本地推送检查读取实际推送的各分支和标签，逐个检查快照与历史。分享图片只接受已经查看过的固定文件；更换图片后需重新查看并更新审核哈希。

维护时修改 `static/`、数据或构建器，再运行 `python build_pages.py`。`docs/` 是生成的发布目录。
