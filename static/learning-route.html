baseline

baseline

科研过程中可反复查验的参考区：经典理论与方法、社区常用工具/协议、采样与不确定性，以及论文必须交代清楚的基础内容。不是入门课程，也不是模型比较中的对照模型；按当前任务查阅，不要求先读完全部原始论文。下方参考专题允许跨阶段引用。

先备知识

  • 科研基本素养：分清自己的实际结果、论文结论和待验证推断；每个科学主张能够找到来源、参数和适用范围。
  • 理论与量纲：理解研究物理量的定义、单位、近似与参考态，知道哪些现象模型能表达，哪些不能。
  • 可复现记录：保存结构来源、许可证/数据许可、软件版本、输入、停止条件、种子与分析过程；异常结果不隐藏。
  • 统计与对照：识别采样相关性、数值/模型/统计误差，以及目标性质需要的独立验证。
  • 科研诚信与安全：不把未执行的计算写成完成，不把自动定位信号当完整参数，不公开订阅全文、凭据或未授权计算资源。
baseline（本页定义）
可长期反复查验的科研常备论文与规范索引，覆盖经典方法、社区实践和科学证据的基本要求；与模型对照、课程难度分级分开。
方法出处
选用的泛函、势、算法和工作流，应能够追溯到原始方法或可靠协议；引用某方法不表示所有默认设置均正确。
SCF 与结构优化
SCF 求给定原子位置的自洽电子态；结构优化改变原子/晶胞。电子收敛和原子受力收敛必须分别检查。
数值精度 / 方法准确性
参数收敛控制数值精度；与参考理论或实验的差异属于准确性与模型局限。参数更大或训练 loss 更低不自动消除模型误差。
采样与不确定性
轨迹帧通常相关；需要说明平衡/生产段、独立重复、拟合区间与误差估计，不能把帧数当独立样本数。
可追溯 / 可复现
保存来源、版本、输入与处理过程，使别人能检查和重算；受版权或许可证限制的资源应提供取得方式而非违规公开。
认可范围
经典方法、社区常用实践与正式工业标准不是同一回事。本页不为每篇论文宣称通用行业认可，也不保证对所有材料都适用。

练习与交付

模拟步骤

  1. 使用 DFT 前查：泛函/赝势与版本、k 点/截断能、电子/离子收敛、磁性/U/色散和参考态是否与问题一致。
  2. 使用 NEB 前查：端点、路径、图像和受力收敛；报告的是静态势垒还是有限温度自由能，不能混称。
  3. 使用 MD 前查：势的适用域、系综/积分器、时间步、守恒/漂移、平衡段、超胞、生产时长与独立重复。
  4. 解释输运前查：坐标展开、MSD 时间窗、跳跃统计、自扩散与集体电导定义，以及温度/相变与外推假设。
  5. 使用 AI/MLIP 前查：数据理论层次、重复/相邻帧泄漏、独立评估、域外与物理性质验证；伪标签不能冒充 DFT 真值。
  6. 写论文或汇报前查：结果是否真实完成、图表/单位是否可复算、替代解释与局限是否清楚、参考与数据许可是否齐全。

通关清单

  • 为自己的项目保留一份“方法—关键设置—出处—适用范围—待核对点”常备表。
  • 每张图能回答一个问题，并追溯到原始结果、分析脚本和对应方法。
  • 每次更换体系、方法或版本时重新检查适用范围；不把一篇论文的参数当永久标准。
  • 按研究主张选择数值对照与物理实验，不把所有测试列成固定套餐。

阅读与书籍

  • The Feynman Lectures on Physics, Volume IIIFeynman、Leighton、Sands · 先读概率幅、态与算符；作为量子概念补课，不替代习题。
  • Density Functional Theory: A Practical IntroductionDavid S. Sholl、Janice A. Steckel · 学习平面波 DFT、简单晶体与计算可靠性；按主题选读。
  • Understanding Molecular Simulation: From Algorithms to Applications（2e）Daan Frenkel、Berend Smit · 选读系综、MD/MC、统计采样与误差。

实验验证分类

  • 数值收敛与重复计算使用相应方法时必做

    这是计算实验：报告单参数对照、目标量与阈值。MD 另需独立初始化、时间窗和采样误差；不规定适用于所有体系的固定轨迹长度。

  • 已有公开结构/性质对照入门验证

    可与公开晶格参数、已知能量差或标准算例对照。温度、成分、缺陷与理论层次须一致或解释差异。

  • XRD / Raman / 基础电化学按研究主张选做

    这里只要求理解测量什么；不要求新手立即制备电池。若论文声称实验验证，应取得真实测量/合作数据，不能用计算图替代。

典型论文段落 / 图表

  • 研究问题与证据边界

    说明模型、尺度、物理量与可验证假设；区别文献事实、自己的计算和未验证推断。

  • 方法与模型口径

    引用原始方法/协议，交代结构来源、理论层次、软件版本、边界、关键参数、停止条件和统计处理。

  • 质量与独立验证

    收敛、守恒/漂移、重复/采样误差、模型对照、独立/OOD 评价，按使用方法与主张挑选。

  • 科学结果与解释

    核心图回答研究问题；给单位、定义和误差；检验替代解释，避免只堆积软件输出。

  • 局限、数据与补充信息

    说明近似、尺度、温度/成分、采样、未覆盖环境；给允许公开的输入、脚本和数据入口，遵守许可。

beginner

入门 · 从教程走到一个可复现算例

先从综述、软件/协议论文建立地图，再选一条任务线完成闭环：结构 → 方法 → 分析 → 文献对照。计算论文无需一上来就包含 DFT、MD、AI 和电芯实验的全部工具。

先备知识

  • 通过 Baseline 的输入、收敛、单位与可复现记录检查。
  • 会读摘要、方法、主图和补充信息；从原文找关键参数，区分软件默认值与作者设置。
  • Python 能读取结构或轨迹，计算统计量并画图；认识 ASE/pymatgen、VASP/VASPKIT、LAMMPS 或 Materials Studio 各自角色。
  • 先选一个任务与一种材料，不同时学习所有软件；MS 标签只表示已整理元数据里的 Materials Studio 使用依据。
结构优化 / 静态计算
先获得合理结构，再对固定结构计算性质。结构优化、DOS 和扩散并不是同一种任务。
DOS 与能带
描述电子态分布与色散。它们可以帮助解释电子性质，但不能单靠能带证明离子导电更好。
MD / AIMD / MLIP-MD
经典 MD 使用经验势；AIMD 逐步计算电子结构力；MLIP 用训练好的能量/力模型驱动 MD。轨迹分析仍需独立验证。
RDF / 配位数
RDF 描述径向结构统计，配位数依赖积分截断与原子对定义。结构峰不是直接的反应证据。
MSD / 扩散系数
展开周期坐标后，在线性扩散时间区间从 MSD 斜率估计 D；3D 各向同性时 D=斜率/6。弹道段、平台段和跳跃不足时不能硬拟合。
复现 / 外推
复现原文模型与条件是第一步；更换成分、温度或软件会引入新问题，不能沿用原文结论。

练习与交付

模拟步骤

  1. 先读 Urban 等电池计算综述或 Butler 等材料机器学习综述，再读 ASE/pymatgen 与 VASPKIT 协议论文；写一页方法选择表。
  2. 任务线 A：选一个简单非磁性晶体做优化和静态性质；完成结构、能量与数值收敛对照，不把软件输出当成机制。
  3. 任务线 B：用可核对的公开 MD 轨迹或可靠示例力场分析 RDF、配位数、MSD 与 D。说明平衡段、生产段、坐标展开及拟合窗口。
  4. 从复现论文的方法与补充信息提取参数表：体系、原子数、模型、时间尺度、软件版本、温度/压力、对照与输出量；缺项标记未知。
  5. 用同一脚本生成重复轨迹结果及误差，不同条件的曲线放在同一坐标轴；先复现趋势再尝试一个小改动。
  6. 形成输入/分析/图表/讨论四部分小报告，注明与原文不一致的资源或模型条件。

通关清单

  • 能独立完成一个原文支持的小复现，不依赖自动问答猜参数。
  • 有一张原文参数提取表、一套图与至少一个失败/偏差解释。
  • 能在组会说明每张图回答哪个问题、对应哪篇论文。
  • 通过复现并不自动形成新论文；下一步先提出可以证伪的研究问题。

阅读与书籍

  • Density Functional Theory: A Practical IntroductionDavid S. Sholl、Janice A. Steckel · 学习平面波 DFT、简单晶体与计算可靠性；按主题选读。
  • Computer Simulation of Liquids（2e）Michael P. Allen、Dominic J. Tildesley · 练习周期边界、积分器、相关函数和输运分析。
  • Electrochemical Methods: Fundamentals and Applications（3e）Allen J. Bard、Larry R. Faulkner、Henry S. White · 选读电极过程、传质、电位参考与阻抗；结合合作实验讨论。
  • VASP 官方分子动力学与过渡态教程VASP 开发团队 · 核对版本相关输入、系综与收敛；参数不能从案例照抄。

实验验证分类

  • 结构与动力学数值对照计算路线必做

    DFT 对照晶格/能量/力；MD 对照 RDF、密度、扩散统计或参考轨迹。按选定任务做，不要求所有指标。

  • XRD、Raman 或 FTIR合作/已有数据可选

    结构与局部环境对照。实验平均结构与模拟单一构型不能一一等同。

  • EIS 与温度依赖电导研究离子输运时相关

    需要几何尺寸、接触、拟合模型与离子/电子贡献说明；缺少这些时不直接用一个电阻数与 D 对比。

  • CV、恒流充放电电极电位/容量主张时相关

    真实电池测试受电解液、负载、倍率和副反应影响；基础电子结构练习不强制做整套测试。

典型论文段落 / 图表

  • 引言 / 综述地图

    问题是什么、采用何种方法、相对哪篇基线改进；综述不是新的实验结果。

  • 模型与步骤图

    给出结构来源、计算流程、关键输入、软件版本及分析步骤。

  • 复现与验证

    主图建议包括结构/流程、收敛/对照、一个核心性质；对照应来自原文或公开基准。

  • 结果与讨论

    解释趋势并列出可能的其他解释，不能只罗列 DOS、RDF、MSD 图片。

  • 局限和补充信息

    列出模型尺度、短轨迹、结构选择、许可与缺失参数；附原始数据和脚本。

路线论文 39 篇，来自精选论文库

intermediate

进阶 · 机制、统计与可靠的 DFT→MD→AI 链条

开始把能量、路径、统计与机制连起来。经典电压/扩散论文和成熟 MLIP 方法放在这里；使用机器学习不是创新本身，要证明其在具体体系里可信且有用。

先备知识

  • 能够复现基础计算，熟悉晶体缺陷、自由能/化学势、势能面和统计采样。
  • 按方向补 DFT+U/磁序/色散、NEB、AIMD 或经典力场参数化；不要混用不相容的参考能。
  • 会做误差传播、独立重复、时间序列相关分析；理解采样不足、有限尺寸与高温外推。
  • AI 路线须掌握训练/验证/测试区别、构型分组、域外检测和物理验证。用于问答的 QLoRA 与用于原子力的 MLIP 是两类模型。
形成能 / 凸包 / 化学势
比较相稳定性需要一致参考态、组成和计算层次。离凸包距离不直接证明可合成，也不包含所有温度/动力学效应。
平均嵌入电压
近似由不同嵌锂状态与 Li 金属参考能的反应能差决定；温度/熵、U 和参考态会改变结果。能量或带隙不是电池电压。
迁移 / 缺陷 / 协同扩散
单离子最小路径、空位浓度和多离子协同运动可能同时影响输运；一个 NEB 势垒不能代表所有机制。
Nernst–Einstein 近似
用自扩散系数估计电导率时忽略离子运动的交叉相关；需明确近似并与集体电导/实验区分。
MLIP 训练域
模型只在足够覆盖的成分、结构、温压、电荷和反应环境中才可能可信；力 RMSE 低不保证正确势垒或长时 MD。
数据泄漏
相邻轨迹帧随机分到训练与测试会过于乐观。按轨迹/结构族/相或材料划分，并检查预训练模型可能见过的来源。

练习与交付

模拟步骤

  1. 选题线 A：重现一个已建立电极的电压/相稳定性趋势；对磁序、U、结构与参考态做有目的的敏感性检查。
  2. 选题线 B：在固态电解质或缺陷材料中定义迁移端点，做多路径 NEB，并比较端点/图像/受力收敛；必要时用 AIMD 判断机制。
  3. 对输运轨迹开展超胞、时长、独立初始化、拟合时间窗与温度检查；给出 D(T) 的区间，不在无跳跃条件下报告假精度。
  4. 拟合 Arrhenius 前检查同一相和同一机制是否成立；若相变或机制改变，不用一条直线强行外推室温。
  5. AI 线先用冻结的通用势做测试而非立刻训练：对独立 DFT 构型测能量/力，另验证结构、势垒和动态稳定性。
  6. 需要微调时仅生成有明确覆盖目标的 DFT 标签；按独立来源分组，记录增量标签预算，并与未微调模型和简单基线比较。

通关清单

  • 形成一个有明确对照、可检验机制和不确定性说明的小课题。
  • 至少能解释为何某个模型误差会影响最终物理量。
  • 若做 MLIP，测试集和最终输运评估不能使用调参中反复看过的轨迹。
  • 选一条主线深入；并不要求一个硕士课题同时完成所有方法和物理实验。

阅读与书籍

  • Electronic Structure: Basic Theory and Practical Methods（2e）Richard M. Martin · 补足电子结构理论与近似边界；不要求从头通读。
  • Understanding Molecular Simulation: From Algorithms to Applications（2e）Daan Frenkel、Berend Smit · 选读系综、MD/MC、统计采样与误差。
  • Computer Simulation of Liquids（2e）Michael P. Allen、Dominic J. Tildesley · 练习周期边界、积分器、相关函数和输运分析。
  • Electrochemical Methods: Fundamentals and Applications（3e）Allen J. Bard、Larry R. Faulkner、Henry S. White · 选读电极过程、传质、电位参考与阻抗；结合合作实验讨论。

实验验证分类

  • 收敛、有限尺寸、采样与模型对照计算主张必做

    DFT/NEB/AIMD/MLIP 各有不同验证项目；按目标误差预算选择，不存在统一的固定测试步数。

  • EIS、PFG-NMR 或温度依赖电导输运主张的合作对照

    PFG-NMR 多对应自扩散，EIS 测到的电导包含样品与界面影响；与模拟比较时匹配相、成分、温度与尺度。

  • XRD / operando XRD / XAS电极结构与氧化还原对照

模拟步骤

  1. 复现一个公开基准或筛选流程，先训练简单描述符/树模型作为对照。
  2. 去重并按成分/结构族/来源分组，固定独立测试；检查预训练数据重叠。
  3. 报告分组误差、域外失败、置信区间或校准，而非只报整体 R²。
  4. 对少量候选独立计算验证稳定性与目标性质；记录候选落选及标签成本。

限制 / 不外推

  • 随机拆分可能只测到同族插值。
  • 热力学稳定预测不保证可合成或兼容电极。
  • 未知合成/制造约束时不能声称工业最优。

通关清单

  • 一个可重跑且不泄漏的基准与候选验证表。
  • 把“模型高分”与“发现了有效材料”分开报告。

阅读与书籍

  • Density Functional Theory: A Practical IntroductionDavid S. Sholl、Janice A. Steckel · 学习平面波 DFT、简单晶体与计算可靠性；按主题选读。
  • Electrochemical Methods: Fundamentals and Applications（3e）Allen J. Bard、Larry R. Faulkner、Henry S. White · 选读电极过程、传质、电位参考与阻抗；结合合作实验讨论。

实验验证分类

  • 独立 DFT / MD / 人工核验候选筛选必需的独立验证

    模型预测不是标签本身，验证计算也要通过对应的数值/统计基线。

  • 候选合成与目标性质测量声称新材料有效时关键

    需合作团队、许可与安全流程；合成失败是闭环数据，不应删掉只留下成功样品。

典型论文段落 / 图表

  • 数据来源与拆分

    组成/结构覆盖、标签定义、去重、许可与训练历史暴露。

  • 评价与候选验证

    简单基线、独立/OOD 测试、校准/消融、候选真实验证与多目标权衡。

frontier

多尺度：从原子性质到界面、颗粒与电芯

将原子尺度参数带入相场/连续模型，并验证上尺度的不确定性与边界条件；不是把不同软件输出串起来就算多尺度闭环。

开放问题：原子尺度得到的扩散、界面能或反应参数，在哪个尺度和条件下能用于连续模型？误差会怎样传到可观测结果？

进入条件

  • 扩散方程、边界条件、网格收敛与时间积分。
  • 原子参数的定义、温度依赖与不确定性。
上尺度 / 粗粒化
以明确假设把微观统计转成介观/宏观参数；不同尺度的物理量可能同名却不等价。
相场
用连续场描述界面/相演化，需要自由能、迁移率、耦合和边界条件等假设。
可辨识性
多组参数可能同样拟合一个实验；必须设计额外对照区分解释。

练习与交付

模拟步骤

  1. 复现一个已有相场/连续模型，先检查单位、质量/电荷守恒、网格与步长收敛。
  2. 逐个说明微观参数的来源、定义和适用范围，不直接把自扩散替换为所有有效扩散系数。
  3. 对参数区间和边界条件做敏感性/误差传播；比较只用经验参数的基线。
  4. 验证至少一个与目标尺度匹配的可观测量，并报告未被数据约束的参数。

限制 / 不外推

  • 原子 D 不等于电极有效 D，更不等于整电芯寿命。
  • 未约束参数的精细图像不能证明机制唯一。
  • 完整电芯模型通常需要超出原子论文提供的几何与工况数据。

通关清单

  • 一张参数传递图、单位/来源表和敏感性图。
  • 明确哪一步尚缺实验数据或尺度映射证据。

阅读与书籍

  • Computer Simulation of Liquids（2e）Michael P. Allen、Dominic J. Tildesley · 练习周期边界、积分器、相关函数和输运分析。
  • Electrochemical Methods: Fundamentals and Applications（3e）Allen J. Bard、Larry R. Faulkner、Henry S. White · 选读电极过程、传质、电位参考与阻抗；结合合作实验讨论。

实验验证分类

  • 成像、压力依赖、阻抗或电芯工况数据按尺度匹配的合作验证

    需要明确几何、微结构、温度、负载与工作条件，单一曲线往往不足约束所有参数。

  • 守恒与数值基准连续模型必做

    物理实验缺乏时仍应完成守恒、网格、步长与标准算例检查，不伪称电芯验证。

典型论文段落 / 图表

  • 尺度映射与单位表

    原子—介观参数定义、假设、误差、软件与边界条件。

  • 数值与观测验证

    守恒/网格、敏感性与同尺度数据对照，展示不能解释的工况。

frontier

MLIP 可靠性：少标签微调、长程效应与高效推断

从基础势模型进入目标域验证，探索用更少 DFT 标签获得可靠物理性质、以及蒸馏/长程处理的精度—速度权衡。

开放问题：目标性质失真来自势垒、长程相互作用、训练覆盖还是采样？微调/蒸馏节省的成本是否以域外失败为代价？

进入条件

  • 能量/力训练、等变性、独立拆分与动态稳定性。
  • 基准 DFT 层次一致性，目标性质与误差容忍度。
等变性
输入旋转等操作后，向量输出按相应方式变换；对称性正确不自动保证物理精度。
长程效应
电荷、极化或其他非局域影响可能超出局域截断表示，尤其在界面和离子体系需核查。
蒸馏 / 伪标签
较小模型拟合教师模型的输出以加速；伪标签不能当新增独立 DFT 真值。

练习与交付

模拟步骤

  1. 固定一个材料与独立的 DFT/AIMD 验证集，先测试现有通用势的结构、势垒、能量/力和动态稳定性。
  2. 按失败类型选择构型：温度、应变、缺陷、路径、短程或带电环境；记录标注成本。
  3. 比较未微调、目标微调、从头训练与小模型蒸馏，避免验证集反复调参后当最终测试。
  4. 报告物理量误差与速度/显存/MD 稳定性；学生模型必须回到独立 DFT/实验参考验收。

限制 / 不外推

  • 2026 少标签/蒸馏工作是特定体系的证据，不是所有材料都只需要几百个标签。
  • 教师伪标签会继承偏差，不能替代独立标注。
  • 带电反应、长程环境或不同参考理论常需额外方法，不是扩大模型就能解决。

通关清单

  • 一个独立模型验证报告，并定位最主要的物理误差。
  • 若标签预算不足，先做公开模型基准，不把问答 QLoRA 当原子势训练。

阅读与书籍

  • Electronic Structure: Basic Theory and Practical Methods（2e）Richard M. Martin · 补足电子结构理论与近似边界；不要求从头通读。
  • Understanding Molecular Simulation: From Algorithms to Applications（2e）Daan Frenkel、Berend Smit · 选读系综、MD/MC、统计采样与误差。

实验验证分类

  • 独立 DFT / AIMD / 物理基准模型方法必做

    不仅测能量/力 RMSE，还检验目标势垒、结构、输运和失败构型。

  • 结构/热物性/输运测量按具体主张可选

    与实验比较仍需要匹配模型条件；纯方法论文可先做强独立计算基准。

典型论文段落 / 图表

  • 覆盖与预算

    参考理论、构型分组、标签选择、预训练重叠和成本。

  • 可靠性与效率

    物理指标、稳定性、外推、模型消融、吞吐/显存和失败报告。

前沿路线论文 29 篇，可与多个阶段交叉

frontier

可审计计算工作流与 AI 闭环

从结构搜索、高通量与数据平台到自动候选/验证闭环；把真实工具执行、失败处理、来源和权限检查纳入系统。

开放问题：自动系统能否在固定预算和独立评价下减少无效计算、提高候选质量，而不是只生成更流畅的文字？

进入条件

  • 可复现任务、工作流/队列、结构去重与方法验证。
  • RAG 引用核验、工具权限、失败处理与人在环确认。
Agent 工具执行
根据任务选择受限工具、读取结果再决策；静态关键词回答或知识图谱本身不等于自主完成研究。
人在环
对许可、危险实验、集群任务、模型异常与高影响决策由人审核；不是每一步都无限自动执行。
Provenance / 溯源
记录输入、来源、版本、参数、计算状态和输出关系；未执行的计算不能标为成功。

练习与交付

模拟步骤

  1. 先复现一个公开高通量或界面搜索流程，检查结构、参数与输出质量。
  2. 建立任务状态机：待验证 → 执行 → 质量检查 → 可用/失败；限定工具和预算。
  3. 比较人工/规则流程与 AI 选择的候选：独立成功率、质量、成本、无效重试与引用正确性。
  4. 对写入、作业提交、机构访问与实验建立人类确认；不把订阅全文或私人映射上传仓库。

限制 / 不外推

  • 高通量工作流、闭环筛选与聊天 Agent 是相关但不同的能力。
  • 自动化不能扩大数据库下载/许可证或实验安全授权。
  • 只有精美页面与高回答流畅度不能证明研究效率或材料发现能力。

通关清单

  • 一个小而真实的可回放工作流，不先追求全自动实验室。
  • 所有结果有状态和来源；工具失败时系统不编造成功。

阅读与书籍

  • Density Functional Theory: A Practical IntroductionDavid S. Sholl、Janice A. Steckel · 学习平面波 DFT、简单晶体与计算可靠性；按主题选读。
  • Electrochemical Methods: Fundamentals and Applications（3e）Allen J. Bard、Larry R. Faulkner、Henry S. White · 选读电极过程、传质、电位参考与阻抗；结合合作实验讨论。

实验验证分类

  • 端到端真实执行与失败注入系统主张必做

    用可审计输入复跑；测试坏结构、不收敛、缺数据和权限拒绝，不用演示文本代替真实任务。

  • 候选计算/实验验证发现主张时关键

    闭环需真实的独立验证；问答系统只完成检索/解释时应如实注明边界。

典型论文段落 / 图表

  • 目标、状态和工具边界

    明确系统执行哪些动作、预算、权限、失败/停止规则。

  • 评价与案例

    规则/人工基线、独立任务、成本、失败率、物理有效性及引用审计。
