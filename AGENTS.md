# Project and publication rules

- Keep all personal information, accounts, institutional access records, download authorization traces, temporary signed links and credentials out of commits and published files.
- Distill is local context only. Never stage, upload, mirror or deploy a distill directory or its contents, including to a private remote. Keep it outside this repository.
- PDFs, extracted full text, private Zotero identifiers, access manifests, backups, local logs and model weights remain local.
- Public paper affiliations and stable bibliographic identifiers are citation metadata, not personal account or access records. Do not copy acquisition provenance into public metadata.
- Edit authored sources, then run the build. Do not manually patch generated docs.
- Before a push run the full snapshot and history privacy checks. New public history must be clean; an acknowledged baseline is not a substitute for that check.
- Do not restore the retired repository's history or add it as a public branch/tag. Preserve user changes and local data during maintenance.
- For complex work use the available orchestration skill with bounded ownership, then integrate and verify.
