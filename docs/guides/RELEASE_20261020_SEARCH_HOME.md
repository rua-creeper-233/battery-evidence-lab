# 2026-10-20 · 搜索首页与静态导读

## 使用方式

首页以居中的证据搜索框为入口。顶部标签切换论文库、教程和未来方向；AI 应用、基础地图、学习路线、国内论文保留独立页面。深色标签表示当前板块，键盘焦点另有轮廓提示。

右下角机器人第一次点击随机选取主库中的一篇论文，再次点击同一个机器人打开该论文数据卡。“换一篇”重新推荐，“关闭”收起。荐文与查询相关性无关，不会混入无命中问题的检索答案。

## 两种回答模式

- 不连接本地服务：浏览器执行确定性的关键词/字符匹配、查询扩展、相关性排序和规则导读，不调用语言模型。
- 连接本地服务：先显示服务回答及其真实模式说明；下方“静态检索与知识延伸”保留浏览器的独立检索结果与导读。是否调用了模型以本次响应为准，而非仅看连接状态。
- 服务不可用、响应格式异常或工具模式不可用时，回退到静态检索。没有命中的问题不会用随机论文凑结果。

## 数据与边界

当前 211 篇唯一 DOI，各有四类静态问答，共 844 条：目录主题定位、方法/工具标签、范围限制、阅读路线。内容仅由公开书目、中文参考译名和路线记录生成；每条保留 DOI 与字段出处。

这是元数据导读，不是新增 844 条原文事实、完整实验协议或模型训练样本。具体数值、版本、收敛测试及结论仍须阅读原文。QLoRA 数据仍为 793 训练 / 78 验证 / 127 测试，本次没有训练或重新评估模型。

新增论文或修改主题、方法、范围、译名、路线后，先重新生成导读，再刷新公开统计、构建网页：

```powershell
python build_static_qa.py
python update_project_status.py --date 2026-10-20
python build_pages.py
```

构建会验证全部论文覆盖、唯一 DOI、四种意图、确定性的问答与出处、来源指纹；过期或篡改的数据在写入公开网页前报错。浏览器缺少导读数据时仍保留原有检索能力。

公开包只含书目、整理说明及教学资料，不包含受限全文、个人本机路径、私有 Zotero 键、凭据或模型权重。当前发布快照检查不能代替历史提交的隐私治理。
