## 论文详情

精选20篇增加六类要点：研究问题、材料体系、计算或实验方法、主要发现、适用边界与复现提示。每条要点保留来源及定位，阅读建议与文献事实分别标记；实体关系用于串联对象、方法与性质。

组织方式参考蔡祎然等《面向AI_for_Science的科技文献数据集体系构建研究——以有机太阳能电池领域为例》的文献数据分层与实体关系思路，采用人工整理的L1–L2证据单元。[原文记录](https://link.cnki.net/urlid/10.1478.G2.20260303.1619.002)。

静态目录导读同步为247×4＝988条。新增书目与模型训练分别维护，本版没有重新训练模型。
