# 2026-10-20 · 从论文导读到科研静态问答

## 新增的内容

40 个独立整理的专题问答，分为 11 个基础知识、12 个计算流程和 17 个常见问题。不把逐篇摘要或方法标签改个标题后当成科研答案。

内容覆盖 DFT 与 MD 的关系、VASP 四个输入文件、电子/离子/数值收敛、几何优化、平均嵌锂电压、NEB/IDPP、AIMD 扩散统计、MSD 单位换算、RDF、电导相关性、经典力场与 SEI、MLIP 数据与验证、界面模型。

每条包含：回答、按顺序的操作步骤、验收检查、适用边界、对应库内论文及可核对的章节/方法位置；软件行为另引官方文档。40 个专题问答与原有 844 条逐篇元数据导读独立维护。

## 怎么使用

首页可试：

- `DFT是什么`
- `VASP结构优化怎么做`
- `NEB和AIMD有什么区别`
- `MSD斜率怎么算D`
- `平均电压工作流`
- `MLIP随机切分问题`

无需本地模型：专题答案在相关论文检索结果前显示。连接本地服务：服务回答在上，下方“静态检索与知识延伸”包含相同的专题答案。静态部分是可解释的主题/关键词匹配，不是实时语言模型推理；没匹配的知识问题不随机凑答案。

“对应论文与官方文档”可展开查看。论文原题下的中文标题是参考译名；DOI 用于核对原文。来源支持的范围有单独说明，多文献综合步骤不表示每篇论文都做过全部步骤。

## 不编的部分

- 不提供对所有材料通用的 ENCUT、k 点、U 值、温度、步长或误差阈值。
- 金属 Li 参考与孤立 Li+ 不能在电压公式中直接替换；输入能量与转移电子数须统一归一化。
- IDPP 优化初始路径几何，不只改变图像间距；NEB 端点可以改变成键关系，但原子组成与映射须一致。
- Nernst–Einstein 估计不是实际电导的普遍上界；交叉相关必须带电荷权重。
- MSD 单位例题明确是演算假设，不是论文结果。未见到正常扩散区就不硬报 D。
- 确定性问答不等于重新训练 QLoRA，也不代表科研准确率已通过独立模型评测。

## 维护

`data/research_knowledge.json` 存放人工整理的专题内容；`validate_research_knowledge.py` 检查结构、论文 ID/DOI、来源、边界及官方链接。`build_pages.py` 在写网页前校验；浏览器遇到缺失或异常知识文件会保留基本检索。

```powershell
python validate_research_knowledge.py data/research_knowledge.json
python build_static_qa.py
python update_project_status.py --date 2026-10-20
python build_pages.py
```

论文 PDF 与 Zotero 的附件/条目映射仅保存在本机，不随本版推送 GitHub。本机全文齐备情况与公开书目数量不是一个指标；缺失全文不标成已下载，客户端导入也不冒充 Zotero 云同步成功。
