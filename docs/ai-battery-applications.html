AI 在电池材料模拟中的应用

一个可执行的 AI 课题需要明确物理量、一致的标签、目标域留出测试，以及 DFT、实验或机制指标复核。下面的应用场景是研究设计。

两类训练用途不同：QLoRA 微调语言模型，适合把文献、输入输出和拒答规则做成科研助手；MLIP 训练原子间力场，学习能量/力/应力以运行结构优化或 MD。它们的模型、标签、损失和验收标准不同，不能互相替代。随机留出可测 IID 泛化；相关轨迹、材料或时间组应按组切分，部署到未见相/组成时另设领域测试。

01 · 固态电解质

固态电解质扩散：MLIP 延长 AIMD 的时间尺度

先用一致的 DFT 能量、力、应力标签训练或适配 MLIP，再在更大超胞中做 MLMD，分析 Li 位移、温度依赖和扩散机制。目标不是“模型 MAE 最低”，而是目标温度、缺陷和结构相上的动力学是否可信。

输入 → 输出结构 + DFT E/F/σ → 势能、优化结构、轨迹、MSD、Arrhenius 活化能。
必须检查标签参数一致；按化学环境/温度留出；区分 tracer conductivity 与 correlated conductivity。

02 · 液态 / 聚合物电解质

液态与聚合物电解质：筛选配方与输运趋势

把盐、溶剂/聚合物组成、温度和含量作为特征，预测电导率、扩散或玻璃化温度的趋势，再回到分子模拟和实验条件核对。不同测量协议、含水量和电极极化会让“同一性质”并不等价。

输入 → 输出组成 + 温度 + 条件 → 排名、区间和候选解释。
验收按时间/配方留出；报告不确定性；至少回溯一组公开测量。
PEMD · Digital Discovery 2026
03 · 反应性 SEI

反应性 SEI：主动学习找“模型没见过”的构型

从小型 Li/电解液界面和短 AIMD 出发，用不确定性挑选断键、成键、非晶和带电构型补充 DFT 标签。SEI 是反应化学与长时间结构演化的交叉问题，不能把晶体训练集直接当作安全保证。

输入 → 输出界面轨迹/扰动结构 → 候选标注集、反应事件、短程结构。
验收留出反应片段、温度和界面；同时看能量、力与事件。
SEI MLIP · npj Comput Mater 2026
04 · 正极 / 高通量

正极稳定性：GNN 与高通量候选排序

用图神经网络或简单基线预测结构/组成代理指标，例如形成能、体积变化或相稳定趋势；将元素、成本和合成窗口作为约束，而不是只追求一个预测分数。候选必须回到 DFT 或实验回溯。

输入 → 输出晶体图 + 组成 → 性质区间、Pareto 候选和解释。
验收时间切分、去重、重复训练方差；报告约束违例。

05 · 界面 / 跨尺度

界面与跨尺度：从局部势垒到器件可观测量

把 DFT/NEB 的局部势垒、MLMD 的轨迹统计和连续尺度模型连接起来；界面厚度、净电荷、电场和晶界都要作为条件记录。必要时用 PINN 表达守恒或边界约束，但 PINN 不会自动补齐缺失的物理和数据。

输入 → 输出结构/势垒/边界条件 → 通量、浓差、阻抗或可比的实验量。
验收尺寸与时间收敛；守恒残差；与至少一组公开测量比数量级。

06 · 证据助手

科学证据 Agent：把问题、计算和论文串起来

QLoRA 适合微调“如何引用、如何暴露未知、如何生成输入输出检查”的语言模型助手；它检索和编排证据，不替代 DFT、MLIP 或实验。每个答案应保留 DOI、日期、模型版本和未验证假设。

输入 → 输出研究问题 + 结构/日志 + 论文 → 可追踪方案、命令草稿、风险清单。
验收引用可打开；拒答越界结论；与人工基准答案做回归测试。

输出检查
